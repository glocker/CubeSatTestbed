# Test strategy

v1 tests are deterministic and should run without SocketCAN by default.

Planned coverage:

- CSP v2 single-frame pack/unpack tests against repository-owned golden vectors
  generated by `tests/golden_vectors/bin/csp_client`, a C helper built from
  official libcsp `v2.1` at commit `48f7fb0` and exercised on `vcan0`, with a
  sibling `*.meta.toml` file for each traffic dump;
- signal codec tests for byte offsets, endian handling, scalar numeric types,
  scale and offset;
- `InMemoryBusAdapter` integration tests for scenario execution in CI;
- per-module model tests for Generic EPS, OBC Peer and Simple Payload;
- fault injection tests for `state_override`, `signal_override`, and named fault
  flags;
- scenario runner PASS/FAIL result tests.

SocketCAN/HIL tests are separate because they require Linux CAN support and a
configured `vcan0` or physical CAN adapter.
